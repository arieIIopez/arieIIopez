# Organización del archivo personal

Este directorio reúne materiales que complementan el README público del perfil sin sobrecargarlo.

## Estructura

- `prensa/`: entrevistas, apariciones y recortes de prensa.
- `columnas/`: columnas de opinión publicadas en medios.
- `mapas/`: mapas, visualizaciones y herramientas cartográficas.
- `apps/`: aplicaciones y prototipos públicos.
- `cv/`: versiones del currículum y antecedentes profesionales.

Cada colección puede crecer de forma independiente y, cuando exista suficiente contenido, incorporar metadatos estructurados para búsqueda y reutilización.

El `README.md` de la raíz se mantiene exclusivamente como presentación del perfil de GitHub.
